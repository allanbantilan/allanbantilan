## Projects

### [POS Management System](https://github.com/allanbantilan/pos-management-system-web)
`Laravel` `Vue 3` `Inertia` `MySQL` &nbsp;&middot;&nbsp; [Live demo](https://posmanagement.duckdns.org)

A cashier app for shops. Staff search products, ring up sales, take cash or online payments,
and print receipts, while owners track stock and view sales reports.

### [Bookbound &mdash; Online Booking System](https://github.com/allanbantilan/booking-system-web)
`Laravel` `Vue 3` `Tailwind` `MySQL` &nbsp;&middot;&nbsp; [Live demo](https://bookbound.duckdns.org)

An online booking app. Customers find listings, reserve and pay online, and manage or cancel
bookings, while owners handle reservations, refunds, and payments.

### [Aurora AI CLI](https://github.com/allanbantilan/aurora-ai-cli)
`Node.js` `JavaScript`

A CLI coding agent with PHP/Laravel-aware workflows. Interactive and one-shot modes, file and
shell tools, multiple AI providers with fallback, and permission modes for safe edits.
